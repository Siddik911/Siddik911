<h2>📄 <strong>Bangla MCQ Questions PDF</strong></h2>

<p>This repository includes a PDF document with Bangla multiple-choice questions (MCQ). The PDF contains <strong>only questions and options</strong> — no solutions or diagrams.</p>

<h3><strong>Files:</strong></h3>
<ul>
  <li><code>docs/questions_bangla.pdf</code> - Generated PDF with questions</li>
  <li><code>docs/questions_bangla.md</code> - Source content in Markdown format</li>
  <li><code>scripts/generate_pdf.py</code> - Python script to generate the PDF</li>
  <li><code>requirements.txt</code> - Python dependencies</li>
</ul>

<h3><strong>How to Regenerate the PDF:</strong></h3>

<h4>Prerequisites:</h4>
<ul>
  <li>Python 3.6 or higher</li>
  <li>pip (Python package installer)</li>
  <li>Bangla font support (automatically installed on most Linux systems)</li>
</ul>

<h4>Steps:</h4>
<ol>
  <li><strong>Install dependencies:</strong>
    <pre><code>pip install -r requirements.txt</code></pre>
  </li>
  <li><strong>Install Bangla fonts</strong> (on Ubuntu/Debian):
    <pre><code>sudo apt-get install fonts-noto-core fonts-noto-ui-core</code></pre>
  </li>
  <li><strong>Run the generation script:</strong>
    <pre><code>python3 scripts/generate_pdf.py</code></pre>
  </li>
</ol>

<p>The script will read the questions from <code>docs/questions_bangla.md</code> and generate <code>docs/questions_bangla.pdf</code>.</p>

<h3><strong>How to Update Questions:</strong></h3>
<ol>
  <li>Edit the <code>docs/questions_bangla.md</code> file with your questions in Bangla</li>
  <li>Follow the existing format: Questions should be numbered ০১-০৮ with options ক, খ, গ, ঘ</li>
  <li>Run <code>python3 scripts/generate_pdf.py</code> to regenerate the PDF</li>
  <li>The new PDF will be created at <code>docs/questions_bangla.pdf</code></li>
</ol>

<p><strong>Note:</strong> The PDF generation script ensures that only questions and options are included. No solution text or diagrams are added to the PDF.</p>
